# Simple .exe Maker

자주 쓰는 프로그램이나 스크립트를 원하는 곳에서 실행할 수 있도록 작은 Windows 런처 EXE를 만듭니다. 런처를 바탕화면이나 다른 폴더에 옮겨 두고 리모컨처럼 실행하면, 원본은 제자리에 둔 채 열 수 있습니다. 런처가 원본의 경로를 기억하므로 원본을 옮겼다면 런처를 다시 만들어 주세요.

아이콘 이미지를 따로 준비할 필요 없이 실행 대상 하나만 끌어 놓아도 됩니다. EXE의 내장 아이콘이나 바로가기에 지정된 아이콘을 가져오고, BAT와 CMD는 Windows 파일 형식 아이콘을 사용합니다. 다른 아이콘을 쓰고 싶다면 실행 대상과 이미지를 함께 끌어 놓으세요.

이 프로그램은 Windows 11 환경에서 개발했습니다. Linux, macOS 등 다른 환경에서의 동작은 보장하지 않습니다.

## 시작하기

1. [Releases](../../releases)에서 `Simple_.exe_Maker_v2.4.1.zip`을 내려받아 압축을 풉니다.
2. 기존 아이콘을 쓰려면 실행 대상 하나를, 아이콘을 바꾸려면 실행 대상과 이미지 하나를 함께 선택합니다.
3. 선택한 파일을 `Simple_.exe_Maker_v2.4.1.bat` 위에 끌어 놓습니다.
4. 저장 위치로 Maker 폴더 또는 바탕화면을 고른 뒤 생성된 EXE를 실행합니다.

| 입력 | 지원 형식 |
| --- | --- |
| 실행 대상 | BAT, CMD, LNK, EXE |
| 사용자 지정 아이콘 | ICO, PNG, JPG, JPEG, BMP, GIF, TIF, TIFF |

ICO를 제외한 이미지는 정사각형이어야 합니다. 런처를 만들려면 Windows와 .NET Framework 4.x의 C# 컴파일러(`csc.exe`)가 필요합니다. Maker는 먼저 Windows의 .NET Framework 폴더에서 컴파일러를 찾습니다. 설치가 필요한 경우 [Microsoft 공식 .NET Framework 다운로드](https://dotnet.microsoft.com/ko-kr/download/dotnet-framework)에서 Windows 버전에 맞는 버전을 확인하세요.

## 아이콘과 실행 경로

- EXE는 내장 아이콘을, LNK는 바로가기에 지정된 아이콘을 우선 사용합니다. BAT와 CMD에는 Windows 파일 형식 아이콘을 사용합니다. 자동 추출에 실패하면 기본 아이콘으로 런처를 생성합니다.
- LNK를 입력하면 대상 경로, 실행 인수, 작업 폴더와 창 상태를 읽습니다. 실행 인수가 필요하면 작동 중인 바로가기를 입력하세요.
- 런처는 기존 파일을 원래 경로에서 호출합니다. 실행 대상을 옮기면 새 경로에서 런처를 다시 만들어야 합니다.
- 아이콘 캐시를 구분하기 위해 실제 파일명에 보이지 않는 유니코드 문자가 붙습니다. 생성한 EXE에는 디지털 서명이 없습니다.
- Maker는 BAT 하나로 실행됩니다. 내부에서 Windows PowerShell과 C# 컴파일러를 호출합니다.

Windows 11에서 별도 이미지 없이 실행 대상의 기존 아이콘을 사용해 런처를 만들고, 만든 런처를 다른 폴더로 옮긴 뒤에도 원본이 실행되는 것을 확인했습니다.

## 이용 허가

이 프로그램을 사용하거나 수정(개조)할 수 있으며, 원본과 수정본을 무료로 재배포할 수 있습니다. 원본이나 수정본을 판매하거나, 다운로드 또는 제공의 대가로 요금을 받는 것은 허용하지 않습니다. [이용 허가 전문](LICENSE.md)
