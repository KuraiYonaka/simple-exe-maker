Simple_.exe_Maker v2.4.0 사용설명서

[프로그램의 목적]
실행 대상의 경로와 실행 정보를 기억하고, 사용자 지정 아이콘을 내장한
작은 런처 EXE를 생성합니다. 원본 프로그램이나 스크립트를 내장하지 않습니다.

[사용 방법]
1. ZIP을 원하는 폴더에 압축 해제합니다.
2. 기존 아이콘을 쓰려면 실행 대상 1개만 선택합니다.
   아이콘을 바꾸려면 실행 대상 1개와 이미지/ICO 1개를 함께 선택합니다.
3. 선택한 파일을 Simple_.exe_Maker_v2.4.0.bat 위로 드래그 앤 드롭합니다.
   2개 입력 시 순서는 무관합니다.
4. 컴파일 완료 후 저장 위치를 선택합니다.
   [1] Maker BAT가 있는 폴더 / [2] 바탕화면
5. 저장된 런처 EXE를 실행합니다.
완성된 v2.4.0 BAT가 포함되어 있으므로 기존 버전이나 업데이트 BAT는 필요 없습니다.

[지원하는 입력]
실행 대상: .bat / .cmd / '바로가기'(.lnk) / .exe 중 1개
아이콘(직접 지정할 때만 추가): .ico / .png / .jpg / .jpeg / .bmp / .gif / .tif / .tiff 중 1개
ICO 이외의 이미지는 가로와 세로 크기가 같은 정사각형이어야 합니다.
비정사각형 이미지는 안내 후 생성이 취소됩니다. 자동 크롭이나 왜곡은 하지 않습니다.
일반 이미지는 256, 128, 64, 48, 32, 24, 16픽셀의 멀티사이즈 ICO로 임시 변환됩니다.

[아이콘 자동 가져오기]
- 실행 대상 1개만 넣으면 자동 모드입니다. 별도 이미지 위치를 알 필요가 없습니다.
- EXE: 파일에 내장된 첫 아이콘 그룹에서 가능한 모든 프레임을 보존합니다.
- LNK: 별도 지정 아이콘(ICO/EXE/DLL 및 인덱스)을 우선 사용합니다.
  지정 아이콘을 읽지 못하면 실제 실행 대상의 아이콘으로 대체합니다.
- BAT/CMD: Windows 파일 형식 아이콘을 사용합니다.
- Windows 대체 방식에서는 단일 크기 아이콘이 나올 수 있습니다.
- 자동 추출이 모두 실패해도 안내 후 기본 EXE 아이콘으로 런처를 생성합니다.
- 실행 중에만 표시하는 창/작업 표시줄 아이콘까지 복제하는 기능은 아닙니다.
- 자동 추출 아이콘은 임시 파일로만 만들며 완료 후 정리합니다.
- 사용자 지정 이미지 입력 시 자동 모드는 사용하지 않습니다.

[실행 대상별 처리]
- BAT/CMD: 원본 절대경로와 해당 폴더를 작업 디렉터리로 기억합니다.
- LNK: 대상 경로, 실행 인수, 작업 디렉터리와 창 상태를 읽어 대상을 직접 실행합니다.
- EXE: 원본 경로와 해당 폴더를 직접 사용하며 기본 창 상태는 일반 창입니다. 별도 실행 인수는 추가하지 않습니다.
특별한 실행 인수가 필요한 경우 실제로 작동하는 LNK를 입력하세요.

[저장 및 아이콘]
- EXE 파일명 끝, 확장자 앞에 보이지 않는 12자리 식별자가 추가됩니다.
- 실제 최종 경로가 이미 존재하면 다른 식별자를 생성합니다.
- 무작위 재추첨 32회 후에는 전체 조합을 순차 확인하며, 모두 사용 중이면 안내 후 중단합니다.
- 원본 EXE와 같은 폴더에 저장할 때에는 표시 이름에 Launcher를 붙입니다.
- 아이콘 캐시 강제 갱신, 캐시 삭제, Explorer 재시작을 하지 않습니다.
- 원본 실행 파일과 아이콘 입력 파일을 수정하지 않습니다.
- 임시 파일은 처리 종료 시 정리합니다.

[주의사항]
- 런처 생성 후에도 실제 실행 대상은 원래 경로에 있어야 합니다.
- LNK 입력 시 원본 LNK 자체는 일반적으로 필요 없지만 실제 대상은 필요합니다.
- 특수 Shell 바로가기 등 일반 실행 대상이 없는 LNK는 지원하지 못할 수 있습니다.
- 아이콘을 바꾸려면 Maker로 런처를 다시 생성하세요.
- 숨은 문자는 실제 파일명 일부이므로 경로 복사나 동기화 도구에서 드러날 수 있습니다.
- 표시 이름이 같은 런처가 여러 개 생길 수 있으므로 불필요한 이전 런처는 직접 정리하세요.
- 생성 EXE에는 디지털 서명이 없습니다.

[요구사항]
Windows 및 .NET Framework 4.x C# 컴파일러(csc.exe).
Maker BAT는 Windows 기본 스크립트 기능을 내부에서 사용합니다.
별도 스크립트 파일을 준비하거나 직접 명령어를 입력할 필요는 없습니다.

[현재 검증 상태]
기준 원본 v2.2.1은 사용자 환경에서 업데이트 및 정상 동작 검증 완료되었습니다.
v2.4.0은 코드·입력 분기·ICO 구성 및 문서 정적 검사를 수행했습니다.
v2.4.0의 실제 Windows 실행 시험은 수행하지 않았습니다.
