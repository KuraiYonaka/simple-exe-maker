Simple_.exe_Maker 전체 변경사항
버전: v2.4.1

최초 버전부터의 누적 이력을 최신순으로 기록합니다.

[v2.4.0 / 실행 대상 단독 입력 및 기존 아이콘 자동 사용]
- 실행 대상(.bat / .cmd / .lnk / .exe) 1개만 드래그 앤 드롭하는 방식 추가.
- 기존 실행 대상 + 사용자 지정 이미지 2개 입력은 순서 무관하게 유지.
- EXE의 첫 아이콘 그룹을 읽어 포함된 원본 크기·투명도·PNG/DIB 프레임을 ICO로 재구성.
- LNK는 IconLocation에 지정된 ICO/EXE/DLL과 인덱스를 우선 사용. 음수는 리소스 ID로 처리.
- 지정 아이콘이 없거나 읽지 못하면 실제 실행 대상의 내장 아이콘을 확인.
- 내장 리소스 추출이 불가능하면 Windows 대상 아이콘을 사용. BAT/CMD에는 파일 형식 아이콘 사용.
- 리소스 추출 시 원본 EXE/DLL을 실행하지 않고 데이터/리소스로만 매핑.
- Windows 대체 추출은 단일 크기일 수 있으며, 임의 리소스 폴더 검색은 하지 않음.
- 모든 자동 아이콘 추출 실패 시 안내하고 사용자 지정 아이콘 없는 기본 EXE로 생성.
- 자동 추출용 임시 ICO와 보조 코드의 임시 컴파일 결과는 처리 후 정리.
- 저장 위치, 숨은 식별자, 원본 보호, 일반 이미지 자동 변환 기능 유지.
- BAT 단일 실행 파일 유지. 별도 .ps1 또는 외부 도구 배포 없음.
- 내부 TXT 갱신 및 최신순 전체 이력 유지. 인수인계 파일명은 프로그램명_버전_인수인계.txt.

[v2.3.0 / 생성 과정 최적화 및 안정성 개선]
- EXE 입력 시 임시 LNK 생성 및 재분석을 제거하고 경로·작업 폴더·기본 창 상태를 직접 구성.
- 사용자가 입력한 실제 LNK의 실행 정보 분석은 유지.
- 12자리 숨은 식별자를 난수 1회의 12비트 값으로 구성. 문자 종류와 4,096개 조합 유지.
- 충돌 시 무작위 재추첨을 최대 32회 수행하고, 이후 전체 조합을 순차 확인.
- 모든 조합이 사용 중이면 오류 안내 후 종료. 기존 파일은 덮어쓰지 않음.
- 컴파일러 확인을 이미지 변환보다 먼저 수행하여 불필요한 변환 방지.
- 일반 이미지 직접 입력 및 정사각형 자동 멀티사이즈 ICO 변환 유지.
- 사용설명서 및 인수인계 갱신. 전체 변경 이력을 최신순으로 배치.
- 검증: 코드 차이·문서 일치·식별자 전체 조합·ZIP 무결성 점검. v2.3.0 Windows 실행 시험은 수행하지 않음.

[v2.2.1 / 안내 및 문서 정정]
- BAT 기본 사용 안내와 입력 오류 안내에 누락된 .cmd 표기 추가.
- 사용설명서를 완성된 v2.2.1 BAT의 직접 사용 절차로 정정.
- 사용자 검증 완료 상태를 반영.
- 실행 로직과 기존 기능은 변경하지 않음.


[v2.2.1 / CMD 파일 지원 추가]
- 실행 대상 목록에 .cmd 추가.
- .cmd를 .bat와 같은 실행·작업 디렉터리 보존 흐름으로 처리.
- CMD 입력에 대한 안내 문구 추가.
- 검증된 v2.2.0의 실제 BAT 원본을 대상으로 해당 부분만 수정.
- 기존 숨은 파일명 식별자, 이미지 처리 및 저장 동작 보존.


[v2.2.0 / 숨은 파일명 식별자]
- EXE 생성마다 12자리 숨은 유니코드 문자 식별자를 파일명 끝에 추가.
- U+200B와 U+200C 조합으로 4,096개 가능.
- 생성 위치에서 실제 파일명이 이미 존재하면 새 식별자를 다시 생성.
- 사용자에게 보이는 이름을 사실상 유지하면서 Windows에는 새 경로로 인식.
- SHChangeNotify 및 ie4uinit 등 아이콘 캐시 갱신 처리 제거.
- 원본 코드에 포함된 BAT/LNK/EXE, 이미지, 저장 위치 선택 기능 유지.
- 실제 사용자 환경에서 같은 표시 이름으로 다른 아이콘 재생성에 성공.


[v2.1.2 / 아이콘 갱신 방식 수정]
- SHChangeNotify 기반 갱신 시도를 제거.
- 최종 저장 후 ie4uinit.exe -show를 한 번 실행하도록 변경.
- 이 방식으로도 동일 이름 아이콘 캐시 문제가 완전히 해결되지 않음.


[v2.1.1 / 저장 및 표시 처리]
- 컴파일 후 저장 위치 선택 기능 추가.
- [1] Maker 폴더 / [2] 바탕화면.
- 선택한 최종 위치에 EXE 배치 후 아이콘 표시 갱신 요청.
- BAT 시작 부분의 UTF-8 BOM 문제를 개선하여 명령어 표시 방지.
- 콘솔의 계속 진행 안내 문구를 한국어로 정리.


[v2.1 / EXE 입력 지원]
- EXE 파일 직접 입력 지원.
- EXE 입력 시 임시 바로가기(.lnk)를 만들어 기존 분석 흐름 재사용.
- 원본 EXE를 수정하지 않고 별도의 런처 EXE 생성.
- 원본 EXE와 출력 경로가 겹치는 경우 원본 파일 보호.
- 파일명·경로에 따른 Windows 아이콘 캐시 잔존 문제 대응 시도.


[v2 / 입력 형식 확장]
- ICO 이외의 일반 이미지 지원: PNG, JPG, JPEG, BMP, GIF, TIF, TIFF.
- 정사각형 이미지를 여러 크기의 ICO 아이콘으로 자동 변환.
- 비정사각형 이미지는 안내 문구를 표시하고 EXE 생성 취소.
- '바로가기'(.lnk) 입력 지원.
- 바로가기에서 실행 대상, 실행 인수, 시작 위치, 창 상태 읽기.
- 생성된 런처는 원본 바로가기 대신 실제 실행 대상을 실행.


[v1 / 초기 버전]
- BAT 파일 1개와 ICO 파일 1개를 드래그 앤 드롭하여 EXE 런처 생성.
- Windows .NET Framework의 C# 컴파일러(csc.exe) 활용.
- EXE에 ICO 아이콘 내장, 원본 BAT 경로와 작업 디렉터리 보존.
- 기존 동일 이름 파일 덮어쓰기 방지: (2), (3) 등 번호 부여.
- 목적: Windows 바로가기 화살표 없이 사용자 지정 아이콘으로 실행.
